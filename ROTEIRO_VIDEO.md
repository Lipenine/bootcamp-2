# Roteiro para o vídeo de 5 minutos

Grave em formato horizontal (16:9), com seu rosto visível e usando sua própria voz. Publique como Público ou Não Listado.

## 0:00–0:30 — Introdução
“Olá, meu nome é [seu nome], sou estudante de [curso/polo]. Vou apresentar o projeto TaskTracker, desenvolvido para a Fase 2 do Bootcamp II. O sistema permite cadastrar e visualizar tarefas.”

## 0:30–2:00 — GitHub
Mostre o repositório publicado. Apresente a árvore de arquivos, o README, o `.gitignore` e o histórico real de commits. Explique brevemente o objetivo de cada arquivo.

## 2:00–4:30 — Demonstração do programa
No terminal, execute `python src/main.py`.
1. Selecione a opção 2 antes de cadastrar tarefas para demonstrar a lista vazia.
2. Selecione a opção 1 e tente deixar o título vazio; mostre que o sistema solicita novamente.
3. Informe um título, uma descrição e uma prioridade inválida; mostre a validação.
4. Informe uma prioridade válida, como “Alta”, e uma data limite.
5. Selecione a opção 2 e mostre a tarefa com status “Pendente”.
6. Selecione a opção 3 para sair.

## 4:30–5:00 — Encerramento
“Essa foi a demonstração da Fase 2 do TaskTracker. Foram implementados o menu, o cadastro, a listagem e as validações de título e prioridade. Como próximo passo, na Fase 3, o projeto poderá ser preparado para testes, empacotamento e Docker.”

Adapte o roteiro ao que você realmente implementou e mostre a execução real. Não afirme que publicou no GitHub até ter feito o `git push`.
